# Security Policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository (Security tab, "Report a
vulnerability"). Do not open a public issue for security problems.

## Scope

ModManifest parses untrusted archives and files. In scope: crashes, resource exhaustion,
path handling, or any behavior that writes, executes or transmits data. Out of scope:
whether a mod is safe to install; ModManifest makes no such claim.

## Supported versions

The latest release.
